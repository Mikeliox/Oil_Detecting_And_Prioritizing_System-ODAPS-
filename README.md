# Oil_Detecting_And_Prioritizing_System-ODAPS-

# Разработка интеллектуальной системы оценки экологических рисков нефтяных загрязнений по спутниковым снимкам для поддержки управленческих решений

## Бизнес-проблема

Для нефтегазовых компаний, морских перевозчиков, портовой инфраструктуры, страховых организаций и экологических операторов нефтяное загрязнение является одновременно экологическим, финансовым и репутационным риском.

При обнаружении потенциального загрязнения необходимо быстро определить:

- существует ли загрязнение на снимке;
- где оно находится;
- какова примерная площадь загрязнения;
- насколько модель уверена в обнаружении;
- требует ли случай приоритетной проверки;
- какие инциденты должны рассматриваться в первую очередь.

Ручной анализ спутниковых изображений требует экспертных ресурсов и плохо масштабируется при большом количестве наблюдений. Поэтому возникает задача автоматического предварительного анализа изображений и ранжирования потенциальных инцидентов по уровню риска.

## Цель работы

Разработать и исследовать модель автоматической сегментации нефтяных загрязнений на спутниковых изображениях и прототип системы поддержки принятия решений, позволяющий использовать результаты модели для первичной оценки и приоритизации экологических инцидентов.

## ML-задача

Основной исследовательской задачей является сегментация нефтяных пятен на SAR-снимках.

В качестве факторов, влияющих на качество модели, исследуются:

- качество исходной разметки;
- использование признаков разных уровней Transformer-модели;
- сложные фоновые объекты и природные явления, визуально похожие на загрязнение.

**Базовая модель:** U-Net.

**Исследуемая модель:** Transformer-based segmentation model / ViT-UNet с использованием многоуровневых признаков.

## Исследовательская гипотеза

Использование признаков нескольких уровней Transformer позволит лучше учитывать одновременно локальные границы нефтяного пятна и глобальный контекст морской поверхности, а повышение качества обучающей разметки позволит снизить количество ложных обнаружений и пропущенных загрязнений.

## Бизнес-слой решения

Результатом работы является не только segmentation mask.

Для каждого обнаруженного потенциального инцидента система формирует карточку:

> спутниковый снимок → обнаруженное загрязнение → площадь → уверенность модели → уровень риска → приоритет проверки

Например:

### Инцидент №143

| Показатель | Значение |
| --- | --- |
| Вероятность загрязнения | 93% |
| Оценочная площадь | 4,7 км² |
| Уверенность модели | высокая |
| Близость к береговой линии | высокая |
| Приоритет проверки | критический |

Таким образом, модель используется как инструмент предварительного отбора инцидентов для дальнейшей экспертной проверки.

## Возможная модель оценки риска

На уровне курсовой работы необязательно рассчитывать реальный финансовый ущерб.

Можно сформировать условный **Environmental Risk Score**, учитывающий:

- площадь обнаруженного загрязнения;
- уверенность модели;
- близость к береговой линии;
- близость к портовой или иной значимой инфраструктуре;
- наличие потенциально чувствительной природной территории.

На основе Risk Score система ранжирует обнаруженные случаи.

Это превращает задачу из:

> «найти нефтяное пятно на картинке»

в:

> «определить, какие потенциальные экологические инциденты требуют наиболее срочной проверки и управленческой реакции».

## Оценка качества

Работа должна оцениваться в двух плоскостях.

### Качество ML-модели

IoU / mIoU, Dice, Precision, Recall, Boundary F1, Recall небольших загрязнений.

Особенно важно анализировать **False Negative**, поскольку пропуск реального загрязнения потенциально критичнее лишнего направления случая на экспертную проверку.

### Качество системы поддержки решений

можно исследовать, насколько использование ML позволяет сократить число изображений, требующих ручной проверки, при сохранении высокой доли обнаруженных загрязнений.

Например:

> Какую долю всех изображений необходимо передать эксперту, чтобы среди них осталось 95% реально загрязненных сцен?

Такая метрика уже хорошо связывает машинное обучение с бизнес-процессом.

## Данные

Основной датасет — **Refined-SOS / Deep-SAR Oil Spill Dataset**.

Дополнительно MADOS или MARIDA могут использоваться для анализа природных и антропогенных объектов, которые могут быть ошибочно приняты моделью за загрязнение.

## Итоговый результат курсовой

- Исследовательский анализ качества исходной разметки.
- Baseline-модель сегментации.
- Transformer-based модель.
- Исследование многоуровневых признаков.
- Анализ влияния исправленной разметки.
- Анализ ошибок модели.
- Модуль оценки экологического риска.
- Прототип панели мониторинга потенциальных инцидентов.

Итоговый пользователь системы — не специалист по компьютерному зрению, а условный **risk manager / эколог / оператор мониторинга / сотрудник страховой или морской компании**, которому необходимо быстро понять, какие случаи требуют внимания в первую очередь.
